5.1 Searching Algorithms

Searching is the algorithmic process of locating a specific target element (often called a key) within a collection of data items stored in linear memory or data structures.

Sorting is the process of arranging a collection of data elements in a specific order, either ascending or descending. Efficient searching algorithms, such as Binary Search, depend directly on data being sorted beforehand.

1. Linear Search (Sequential Search)

Linear Search sequentially checks each element of an array from left to right until the desired target key is located or the end of the array is reached. It does not require elements to be ordered or sorted.

Linear Search Algorithm:

  1. Start from index i = 0.
  2. Compare arr[i] with target value key.
  3. If arr[i] == key, search is successful. Return index i.
  4. If arr[i] != key, increment i = i + 1.
  5. Repeat steps 2–4 while i < n.
  6. If i == n without finding key, return -1 (element not found).

Step-by-step Example Trace (Search Key = 7):

Consider the array arr = [12, 35, 7, 42, 19] with n = 5:

Time Complexity Analysis:

  • Best Case: $O(1)$ — Target key is located at index 0 (1 comparison).
  • Worst Case: $O(n)$ — Target key is at the last index n-1 or absent ($n$ comparisons).
  • Average Case: $O(n)$ — On average, elements are found after $\frac{n+1}{2}$ comparisons.
  • Space Complexity: $O(1)$ auxiliary space.

Program P1: Linear Search in C

#include <stdio.h>

int linearSearch(int arr[], int n, int key) {
    int i;
    for (i = 0; i < n; i++) {
        if (arr[i] == key) {
            return i; // Target found at index i
        }
    }
    return -1; // Target not found
}

int main() {
    int arr[] = {12, 35, 7, 42, 19};
    int n = sizeof(arr) / sizeof(arr[0]);
    int key = 7;

    int result = linearSearch(arr, n, key);

    if (result != -1) {
        printf("Element %d found at index %d.\n", key, result);
    } else {
        printf("Element %d not found in the array.\n", key);
    }

    return 0;
}

Merits and Demerits of Linear Search:

Merits Demerits
Simple to implement and easy to understand. Inefficient for very large datasets ($O(n)$ comparisons).
Works on unsorted arrays and linked lists. Slow response time in worst-case scenario.
Requires no additional memory or data pre-processing. Redundant comparisons made when array is already sorted.

2. Binary Search

Binary Search is an efficient divide-and-conquer search algorithm that works strictly on sorted arrays. It works by repeatedly comparing the target key against the middle element of the array.

Iterative Binary Search Algorithm:

  1. Set low = 0 and high = n - 1.
  2. Calculate mid = low + (high - low) / 2.
  3. If arr[mid] == key, search is successful; return mid.
  4. If key < arr[mid], search lower half by updating high = mid - 1.
  5. If key > arr[mid], search upper half by updating low = mid + 1.
  6. Repeat steps 2–5 while low <= high. Return -1 if not found.

Step-by-Step Example Trace (Search 44 in Sorted Array):

Consider array: arr = [11, 22, 33, 44, 55, 66, 77, 88, 99] (n = 9):

Time Complexity Derivation:

At each division step, the search space size is halved: $$n \longrightarrow \frac{n}{2} \longrightarrow \frac{n}{4} \longrightarrow \dots \longrightarrow 1$$ After $k$ recursive/iterative divisions, $\frac{n}{2^k} = 1 \implies 2^k = n \implies k = \log_2(n)$.

  • Best Case: $O(1)$ (when middle element matches key immediately).
  • Worst Case: $O(\log_2 n)$.
  • Average Case: $O(\log_2 n)$.
  • Space Complexity: $O(1)$ iterative, $O(\log_2 n)$ recursive call stack.

Program P2: Iterative & Recursive Binary Search in C

#include <stdio.h>

// Iterative Binary Search
int binarySearchIterative(int arr[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
            return mid; // Key found
        if (arr[mid] < key)
            low = mid + 1; // Search right subarray
        else
            high = mid - 1; // Search left subarray
    }
    return -1; // Key not present
}

// Recursive Binary Search
int binarySearchRecursive(int arr[], int low, int high, int key) {
    if (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
            return mid;
        if (arr[mid] > key)
            return binarySearchRecursive(arr, low, mid - 1, key);
        return binarySearchRecursive(arr, mid + 1, high, key);
    }
    return -1;
}

int main() {
    int arr[] = {11, 22, 33, 44, 55, 66, 77, 88, 99};
    int n = sizeof(arr) / sizeof(arr[0]);
    int key = 44;

    int resIterative = binarySearchIterative(arr, n, key);
    int resRecursive = binarySearchRecursive(arr, 0, n - 1, key);

    printf("Iterative Search: Key %d found at index %d.\n", key, resIterative);
    printf("Recursive Search: Key %d found at index %d.\n", key, resRecursive);

    return 0;
}

Merits and Demerits of Binary Search:

Merits Demerits
Extremely fast for large datasets ($O(\log n)$ time). Requires data array to be strictly sorted first.
Significantly reduces comparison operations. Not directly suited for linked list structures without random access.

5.2 Basic Sorting Algorithms

Sorting is a fundamental operation that reorders elements in non-decreasing or non-increasing order.

1. Bubble Sort

Bubble Sort operates by repeatedly stepping through the list, comparing adjacent elements, and swapping them if they are in the wrong order. With each full pass, the largest unsorted element "bubbles up" to its correct position at the end of the array.

Algorithm:

  1. For i = 0 to n - 2 (Passes):
  2. For j = 0 to n - i - 2 (Comparisons):
  3. If arr[j] > arr[j + 1], swap arr[j] and arr[j + 1].
  4. If no swaps occur in an entire pass, the array is sorted early.

Program P3: Bubble Sort with Early Exit Optimization in C

#include <stdio.h>

void bubbleSort(int arr[], int n) {
    int i, j, temp;
    int swapped;

    for (i = 0; i < n - 1; i++) {
        swapped = 0;
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap elements
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        // If no two elements were swapped in inner loop, break
        if (swapped == 0)
            break;
    }
}

int main() {
    int arr[] = {5, 3, 1, 9, 8, 2, 4, 7};
    int n = sizeof(arr) / sizeof(arr[0]);
    int i;

    bubbleSort(arr, n);

    printf("Sorted array using Bubble Sort:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}

Bubble Sort Complexity: Best Case $O(n)$ (optimized), Worst & Average Case $O(n^2)$. Space Complexity: $O(1)$.

2. Selection Sort

Selection Sort divides the array into a sorted and an unsorted region. In each pass, it selects the minimum element from the unsorted region and swaps it with the first element of the unsorted region.

Pass-by-Pass Trace Example: Array A = {25, 79, 41, 9, 34, 60}

Program P4: Selection Sort in C

#include <stdio.h>

void selectionSort(int arr[], int n) {
    int i, j, minIdx, temp;

    for (i = 0; i < n - 1; i++) {
        minIdx = i;
        for (j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        // Swap minimum element with first element of unsorted region
        if (minIdx != i) {
            temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}

int main() {
    int arr[] = {25, 79, 41, 9, 34, 60};
    int n = sizeof(arr) / sizeof(arr[0]);
    int i;

    selectionSort(arr, n);

    printf("Sorted array using Selection Sort:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}

Time Complexity Derivation: Total comparisons: $$(n-1) + (n-2) + \dots + 1 = \frac{n(n-1)}{2} = \frac{n^2 - n}{2} \in O(n^2)$$ Best, Worst, and Average Case Time Complexity are all $O(n^2)$.

3. Insertion Sort

Insertion Sort builds the final sorted array one item at a time. It takes each element from the unsorted region and inserts it into its correct position within the already sorted sub-array.

Pass-by-Pass Trace Example: Array A = {25, 79, 41, 9, 34, 60}

Pass 1 Key = 79 79 > 25 (No shift required) [25, 79, 41, 9, 34, 60]
Pass 2 Key = 41 Shift 79 right; insert 41 before 79 [25, 41, 79, 9, 34, 60]
Pass 3 Key = 9 Shift 79, 41, 25 right; insert 9 at index 0 [9, 25, 41, 79, 34, 60]
Pass 4 Key = 34 Shift 79, 41 right; insert 34 before 41 [9, 25, 34, 41, 79, 60]
Pass 5 Key = 60 Shift 79 right; insert 60 before 79 [9, 25, 34, 41, 60, 79]

Program P5: Insertion Sort in C

#include <stdio.h>

void insertionSort(int arr[], int n) {
    int i, key, j;
    for (i = 1; i < n; i++) {
        key = arr[i];
        j = i - 1;

        /* Move elements of arr[0..i-1] that are greater than key
           to one position ahead of their current position */
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j = j - 1;
        }
        arr[j + 1] = key;
    }
}

int main() {
    int arr[] = {25, 79, 41, 9, 34, 60};
    int n = sizeof(arr) / sizeof(arr[0]);
    int i;

    insertionSort(arr, n);

    printf("Sorted array using Insertion Sort:\n");
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}

Complexity: Best Case $O(n)$ (already sorted), Worst/Average Case $O(n^2)$. Space Complexity: $O(1)$.

5.3 Finding Roots of Quadratic Equations

A standard quadratic equation is expressed as: $$ax^2 + bx + c = 0 \quad (a \neq 0)$$

The roots are computed using the Discriminant formula $d = b^2 - 4ac$:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Algorithm to Compute Roots:

  1. Input coefficients a, b, and c.
  2. If a == 0, equation is not quadratic; terminate.
  3. Compute Discriminant d = b*b - 4*a*c.
  4. If d > 0: Roots are real and distinct. $$r_1 = \frac{-b + \sqrt{d}}{2a}, \quad r_2 = \frac{-b - \sqrt{d}}{2a}$$
  5. If d == 0: Roots are real and equal. $$r_1 = r_2 = \frac{-b}{2a}$$
  6. If d < 0: Roots are complex and imaginary. $$\text{Real Part} = \frac{-b}{2a}, \quad \text{Imaginary Part} = \frac{\sqrt{-d}}{2a}$$

Complete C Program for Finding Roots:

#include <stdio.h>
#include <math.h>

int main() {
    double a, b, c, discriminant, root1, root2, realPart, imagPart;

    printf("Enter coefficients a, b and c: ");
    if (scanf("%lf %lf %lf", &a, &b, &c) != 3 || a == 0) {
        printf("Invalid input! 'a' must be a non-zero real number.\n");
        return 1;
    }

    discriminant = b * b - 4 * a * c;

    // Condition for real and distinct roots
    if (discriminant > 0) {
        root1 = (-b + sqrt(discriminant)) / (2 * a);
        root2 = (-b - sqrt(discriminant)) / (2 * a);
        printf("Roots are Real and Distinct:\n");
        printf("Root 1 = %.2lf\nRoot 2 = %.2lf\n", root1, root2);
    }
    // Condition for real and equal roots
    else if (discriminant == 0) {
        root1 = root2 = -b / (2 * a);
        printf("Roots are Real and Equal:\n");
        printf("Root 1 = Root 2 = %.2lf\n", root1);
    }
    // Condition for complex/imaginary roots
    else {
        realPart = -b / (2 * a);
        imagPart = sqrt(-discriminant) / (2 * a);
        printf("Roots are Complex and Imaginary:\n");
        printf("Root 1 = %.2lf + %.2lfi\n", realPart, imagPart);
        printf("Root 2 = %.2lf - %.2lfi\n", realPart, imagPart);
    }

    return 0;
}

5.4 Notion of Order of Complexity

Asymptotic Analysis evaluates the performance of an algorithm as the input size $n$ grows infinitely large ($n \to \infty$).

1. Big-O Notation $O(g(n))$ — Upper Bound (Worst Case)

Defines an upper bound for an algorithm's running time. Function $f(n) = O(g(n))$ if there exist positive constants $c$ and $n_0$ such that: $$f(n) \le c \cdot g(n) \quad \forall n \ge n_0$$

2. Big-Omega Notation $\Omega(g(n))$ — Lower Bound (Best Case)

Defines a lower bound for an algorithm's running time. Function $f(n) = \Omega(g(n))$ if there exist positive constants $c$ and $n_0$ such that: $$c \cdot g(n) \le f(n) \quad \forall n \ge n_0$$

3. Big-Theta Notation $\Theta(g(n))$ — Tight Bound (Average Case)

Defines a tight bound. Function $f(n) = \Theta(g(n))$ if there exist positive constants $c_1, c_2$ and $n_0$ such that: $$c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n) \quad \forall n \ge n_0$$

Example Mathematical Proofs:

Example 1: Prove $f(n) = 2n + 1 \in O(n)$
We must show $2n + 1 \le c \cdot n$ for $n \ge n_0$.
For $n \ge 1$: $2n + 1 \le 2n + n = 3n$.
Thus, choosing constant $c = 3$ and $n_0 = 1$, we satisfy $f(n) \le 3n \implies f(n) = O(n)$.
Example 2: Prove $f(n) = 2n - 2 \in \Omega(n)$
We must show $2n - 2 \ge c \cdot n$ for $n \ge n_0$.
For $n \ge 2$: $2n - 2 \ge 2n - n = 1n$.
Thus, choosing $c = 1$ and $n_0 = 2$, we satisfy $f(n) \ge 1n \implies f(n) = \Omega(n)$.
Example 3: Prove $f(n) = 3n - 2 \in \Theta(n)$
We must find $c_1, c_2$ such that $c_1 \cdot n \le 3n - 2 \le c_2 \cdot n$ for $n \ge n_0$.
Lower Bound: $3n - 2 \ge 1n$ for $n \ge 1 \implies c_1 = 1$.
Upper Bound: $3n - 2 \le 3n$ for $n \ge 1 \implies c_2 = 3$.
Therefore, $1n \le 3n - 2 \le 3n$ for $n_0 = 1 \implies f(n) = \Theta(n)$.
