Conditional Branching And Loops

3.1 Writing And Evaluation Of Conditionals And Consequent Branching

Control Structures

By default, instructions in a C program are executed sequentially—one after another from top to bottom. However, complex problems require altering the execution flow based on conditions or repeating a block of instructions until a requirement is satisfied.

A Control Structure is a programming construct that controls the flow of execution in a program.

Advantages of Control Structures:

  • Enable decision-making capability in programs.
  • Allow repetition (looping) without duplicating code.
  • Improve program readability, modularity, and maintainability.
  • Enable efficient problem solving for complex logic.

Types of Control Statements

Control statements in C are broadly classified into two categories:

  1. Conditional Branching Statements: Execution branches to different paths based on whether a conditional expression evaluates to true (non-zero) or false (zero). Examples: if, if-else, nested if-else, switch.
  2. Unconditional Branching Statements: Execution jumps directly to another part of the program without testing any condition. Examples: break, continue, goto, return.

Conditional Branching Constructs

1. Simple if Statement

Executes a block of code only if the condition evaluates to true.

if (condition) {
    // Statement(s) executed if condition is true
}

2. if-else Statement

Executes the if block if the condition evaluates to true, otherwise executes the else block.

if (condition) {
    // Code block 1 (Condition is True)
} else {
    // Code block 2 (Condition is False)
}

Example 1: Even or Odd Check

#include <stdio.h>

int main() {
    int num;
    printf("Enter an integer: ");
    scanf("%d", &num);

    if (num % 2 == 0) {
        printf("%d is even.\n", num);
    } else {
        printf("%d is odd.\n", num);
    }

    return 0;
}

Example 2: Comparing Two Integers (==, >, <)

#include <stdio.h>

int main() {
    int num1, num2;
    printf("Enter two integers: ");
    scanf("%d %d", &num1, &num2);

    if (num1 == num2) {
        printf("Result: %d is equal to %d\n", num1, num2);
    } else if (num1 > num2) {
        printf("Result: %d is greater than %d\n", num1, num2);
    } else {
        printf("Result: %d is less than %d\n", num1, num2);
    }

    return 0;
}

The switch Statement

The switch statement is a multi-way decision maker that tests whether an expression matches one of a number of constant integer or character values, branching accordingly.

Key Keywords:

  • switch: Evaluates an expression against multiple cases.
  • case: Represents a constant value to test against the expression.
  • break: Exits the switch block once a matching case is executed (prevents fall-through).
  • default: Optional block executed if no case value matches the expression.

General Syntax:

switch (expression) {
    case value1:
        // Statements executed if expression == value1
        break;
    case value2:
        // Statements executed if expression == value2
        break;
    default:
        // Statements executed if no case matches
}

Example: Spelling Single-Digit Number in English

#include <stdio.h>

int main() {
    int digit;
    printf("Enter a single digit (0-9): ");
    scanf("%d", &digit);

    switch (digit) {
        case 0: printf("Zero\n"); break;
        case 1: printf("One\n"); break;
        case 2: printf("Two\n"); break;
        case 3: printf("Three\n"); break;
        case 4: printf("Four\n"); break;
        case 5: printf("Five\n"); break;
        case 6: printf("Six\n"); break;
        case 7: printf("Seven\n"); break;
        case 8: printf("Eight\n"); break;
        case 9: printf("Nine\n"); break;
        default: printf("Invalid input! Please enter a single digit (0-9).\n");
    }

    return 0;
}

Unconditional Branching Statements

Unconditional branching transfers program control directly to another statement without checking any condition.

Keyword Syntax Description
break break; Terminates the nearest enclosing loop or switch statement immediately.
continue continue; Skips the rest of the current loop iteration and proceeds to the next iteration.
goto goto label;
...
label: statement;		 Transfers control unconditionally to a specified labeled statement within the same function.
return return expression; Terminates execution of the current function and returns a value to the caller.

3.2 Iteration And Loops

Iteration constructs repeat a block of code as long as a specified condition remains true. C provides three primary loop control structures: while, do-while, and for.

1. The while Statement

A entry-controlled loop where the condition is evaluated before executing the loop body. If the initial condition is false, the loop body never runs.

Syntax:

while (condition) {
    // Loop body
    // Update expression
}

Example: Countdown ("tick 10" down to "tick 1")

#include <stdio.h>

int main() {
    int count = 10;

    while (count >= 1) {
        printf("tick %d\n", count);
        count--;
    }

    return 0;
}

2. The do-while Statement

An exit-controlled loop where the condition is tested after executing the loop body. Guarantees that the loop body executes at least once.

Syntax:

do {
    // Loop body
} while (condition);

Example:

#include <stdio.h>

int main() {
    int i = 1;

    do {
        printf("Iteration number: %d\n", i);
        i++;
    } while (i <= 5);

    return 0;
}

3. The for Loop

An entry-controlled loop that combines initialization, condition checking, and iteration (increment/decrement) in a single concise line.

General Syntax:

for (initialization; condition; iteration) {
    // Loop body
}

Example: Standard for Loop

#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) {
        printf("i = %d\n", i);
    }
    return 0;
}

Example: Comma Operator in Initialization & Iteration

Multiple variables can be initialized and updated simultaneously within a single for header using the comma operator.

#include <stdio.h>

int main() {
    int i, j;
    
    // Multiple initializations (i=1, j=10) and updates (i++, j--)
    for (i = 1, j = 10; i <= 5; i++, j--) {
        printf("i = %d, j = %d\n", i, j);
    }

    return 0;
}

4. Nested Loops

A loop placed inside another loop is called a nested loop. For every single iteration of the outer loop, the inner loop completes all of its iterations.

Example: Nested Loop Program

#include <stdio.h>

int main() {
    int outer, inner;

    for (outer = 1; outer <= 2; outer++) {
        printf("Outer loop pass %d: ", outer);
        for (inner = 1; inner <= 4; inner++) {
            printf(".");
        }
        printf("\n");
    }

    return 0;
}

Program Output:

Outer loop pass 1: ....
Outer loop pass 2: ....

4.1 Array Declaration & Initialization

An Array is a fixed-size, sequential collection of elements of the same data type stored in contiguous memory locations. It is a derived data type used to represent a collection of homogeneous data under a single variable name.

Key Terminology:

  • Array Size: The total number of elements that an array can hold. It must be declared as a constant integer value or constant expression.
  • Index / Subscript: An integer value used to identify and access individual elements in an array. In C, array indexing always starts at 0 and ends at size - 1.

4.2 Bound Checking Arrays (1-D, 2-D)

C language does not perform automatic bound checking on array indices. If a program attempts to read or write beyond the allocated index bounds (e.g., accessing a[5] for an array of size 5), C will access memory outside the array block, leading to undefined behavior, logical errors, or memory corruption without giving a compilation error.

1. One Dimensional Array (1-D Array)

A 1-D array represents a single row or list of data items stored sequentially in contiguous memory locations.

Syntax:

data_type array_name[array_size];

Examples of Declaration & Initialization:

int a[3] = {2, 3, 5};
char ch[10] = "Data";
float x[3] = {2.5, 3.50, 489.98};

Memory Allocation Calculation:

The total memory in bytes allocated for a 1-D array can be calculated using:

Total Size in Bytes = Number of Elements × sizeof(data_type)

int main() {

#include <stdio.h>

int main() {
    int source[5] = {5, 12, 19, 26, 33};

    // Copying elements
    for (i = 0; i < 5; i++) {
        destination[i] = source[i];

        printf("destination[%d] = %d\n", i, destination[i]);

Program 3 (P3): Find the reverse of a 1-D array

#include <stdio.h>

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int i;

    printf("Original Array: ");
    for (i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }

    printf("\nReversed Array: ");
    for (i = 4; i >= 0; i--) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    return 0;
}

Output (P3):

Original Array: 1 2 3 4 5 
Reversed Array: 5 4 3 2 1

2. Multi-Dimensional Array (2-D Array)

A Two-Dimensional (2-D) Array is an array of arrays, logically structured as a matrix with rows and columns.

Declaration Syntax:

data_type array_name[no_of_rows][no_of_columns];

The total number of elements in a 2-D array is calculated as: Total Elements = no_of_rows × no_of_columns.

Example: int a[2][3]; creates a matrix with 2 rows and 3 columns (total 6 elements).

2-D Array Index Grid Diagram (for a[2][3]):

Row \ Column Column 0 Column 1 Column 2
Row 0 a[0][0] a[0][1] a[0][2]
Row 1 a[1][0] a[1][1] a[1][2]

Initialization & Storage Representation

2-D arrays can be initialized in multiple ways during declaration:

// Method 1: Row-wise grouping
int a[2][3] = { {1, 2, 3}, {4, 5, 6} };

// Method 2: Linear list initialization
int a[2][3] = {1, 2, 3, 4, 5, 6};

// Method 3: Omitting row size (Column size is mandatory)
int a[][3] = { {1, 2, 3}, {4, 5, 6} };

Note: In C, when initializing a 2-D array, the column dimension must always be specified, whereas the row dimension can be optionally omitted.

General Storage Representation Matrix Table (Row 0..m-1, Col 0..n-1)

Row \ Column Col 0 Col 1 ... Col n-1
Row 0 A[0][0] A[0][1] ... A[0][n-1]
Row 1 A[1][0] A[1][1] ... A[1][n-1]
... ... ... ... ...
Row m-1 A[m-1][0] A[m-1][1] ... A[m-1][n-1]

Accessing Two-Dimensional Array Elements

Elements in a 2-D array are accessed using row index i and column index j. 

int val = A[1][2]; // Accesses element located at Row 1, Column 2

4.3 Character Arrays And Strings

In C, a String is represented as a one-dimensional array of characters terminated by a null character ('\0').

Index range for a character array of size N spans from 0 to N-1.

Example 1: Difference between Integer Array & Character Array

An integer array int A[5] = {10, 20, 40, 5, 25}; stores numbers directly across indices 0 to 4:

Index 0 1 2 3 4
A[i] 10 20 40 5 25

String Data Type & Abstraction

C does not have a built-in primitive string data type. Instead, string abstraction is provided via character arrays and functions declared inside the <string.h> library header (such as strlen, strcat, strcpy, strrev).

String Manipulation in C Language

  • Null Character ('\0'): Marks the exact end of a string in memory.
  • Format Specifier: %s is used in printf and scanf to handle string operations.
  • Header File: #include <string.h> must be included to utilize string manipulation functions.

Declaration Syntax:

char string_name[size_of_string];

Example: char name[20] = "Program";

Example Instruction Breakdown Table

Sr. No. Instructions Description
1 char str[20]; Declares a character array str capable of storing up to 19 characters + 1 null character.
2 printf("Enter String: "); Prints a prompt message on the screen asking for user input.
3 scanf("%s", str); Reads a single word string from keyboard input into array str (stops reading at whitespace).
4 printf("Entered: %s\n", str); Outputs the stored string onto the console screen.

Common String Manipulation Functions (string.h)

Function Syntax Example Purpose / Description
strlen() len = strlen(str); Calculates and returns the length of the string (excluding the null character '\0').
strcpy() strcpy(dest, src); Copies source string src into destination character array dest.
strcat() strcat(str1, str2); Concatenates (appends) string str2 to the end of string str1.
strcmp() res = strcmp(s1, s2); Compares two strings lexicographically. Returns 0 if equal, <0 if s1 < s2, >0 if s1 > s2.
strchr() ptr = strchr(str, 'a'); Searches for the first occurrence of character 'a' in string str and returns a pointer to it.
