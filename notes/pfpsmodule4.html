Functions, Parameter Passing & Scope

6.1 Introduction & Writing Functions

A Function is a self-contained, reusable block of code designed to perform a specific task. Functions allow complex programs to be broken down into smaller, manageable, and modular sub-problems (a design strategy called Divide and Conquer or Modular Programming).

Syntax of a Function

return_type function_name(parameter_list) {
    // Local variable declarations
    // Statements / Function body
    return return_value; // Optional depending on return_type
}

Components of a Function Definition:

  • Return Type: Specifies the data type of the value that the function returns to the calling routine (e.g., int, float, char). If no value is returned, the keyword void is used.
  • Function Name: A unique identifier used to call/invoke the function following standard identifier rules in C.
  • Parameter / Argument List: A comma-separated list of variable declarations that act as inputs passed into the function from the caller.
  • Function Body: Enclosed within curly braces { ... }, contains instructions executed when the function is called.

Key Advantages of Using Functions:

  • Code Reusability: Write once and execute multiple times without duplicating code.
  • Modularity & Maintainability: Improves code readability and simplifies debugging and testing.
  • Reduction in Program Size: Eliminates duplicate lines of code across the program.
  • Abstraction: Hides complex internal execution details from the caller.

6.2 Scope Of Variables & Functions

Functions in C are categorized into two primary types based on their source and scope: Library Functions and User-Defined Functions.

1. Library Functions (Built-in Functions)

Library functions are predefined, pre-compiled functions provided by the C standard library. To use them, their corresponding header file must be included at the top of the C program using the #include preprocessor directive.

Header File Library Functions Purpose
<stdio.h> printf(), scanf(), gets(), puts() Standard Input / Output operations.
<math.h> pow(), sqrt(), ceil(), floor(), abs() Mathematical and algebraic operations.
<string.h> strlen(), strcpy(), strcat(), strcmp() String manipulation routines.
<stdlib.h> malloc(), free(), exit(), rand() Memory allocation and process control utilities.

2. User-Defined Functions (UDF)

User-defined functions are created by the programmer to perform specific custom requirements. Creating and using a user-defined function involves three fundamental steps:

  1. Function Declaration (Prototype): Informs the compiler about the function name, return type, and parameters prior to its actual call. Syntax: return_type name(data_types);
  2. Function Call: Invokes the function to perform its designated task. Syntax: name(actual_arguments);
  3. Function Definition: Contains the actual statements executed when the function is invoked.

Code Example: Addition of Two Numbers (`add(a, b)`)

#include <stdio.h>

// 1. Function Declaration (Prototype)
int add(int x, int y);

int main() {
    int num1 = 15, num2 = 25, sum;

    // 2. Function Call
    sum = add(num1, num2);

    printf("Sum of %d and %d is: %d\n", num1, num2, sum);
    return 0;
}

// 3. Function Definition
int add(int x, int y) {
    int result;
    result = x + y;
    return result; // Returns sum to calling routine
}

Output:

Sum of 15 and 25 is: 40

6.3 Parameter Passing In Functions

When calling a function, data is passed between the calling routine and the called function through parameters. Parameters are classified into two groups:

  • Actual Parameters (Arguments): Values or variables passed to the function in the function call statement (e.g., num1, num2 inside main()).
  • Formal Parameters: Variables declared in the function definition header that receive the incoming values (e.g., x, y in add()).

1. Call By Value (Pass-by-Value)

In Call by Value, exact copies of the values of actual parameters are passed into formal parameters. The called function creates its own temporary variables in a separate stack memory frame.

Key Rule: Any modifications made to formal parameters inside the called function DO NOT affect the actual parameters in the caller function.

Code Example: `swap(int p1, int p2)` using Call by Value

#include <stdio.h>

// Function Definition (Call by Value)
void swapValue(int p1, int p2) {
    int temp;
    temp = p1;
    p1 = p2;
    p2 = temp;
    printf("Inside swapValue(): p1 = %d, p2 = %d\n", p1, p2);
}

int main() {
    int a = 10, b = 20;

    printf("Before swap: a = %d, b = %d\n", a, b);
    swapValue(a, b); // Actual arguments passed by value
    printf("After swap:  a = %d, b = %d\n", a, b);

    return 0;
}

Output:

Before swap: a = 10, b = 20
Inside swapValue(): p1 = 20, p2 = 10
After swap:  a = 10, b = 20

2. Call By Reference (Pass-by-Pointer)

In Call by Reference, instead of passing values, the memory addresses (pointers) of actual variables are passed to the function's formal parameters.

Key Rule: Dereferencing pointers allows the called function to directly access and modify original variable values in caller memory.

Code Example: `swap(int *p1, int *p2)` using Call by Reference

#include <stdio.h>

// Function Definition (Call by Reference)
void swapRef(int *p1, int *p2) {
    int temp;
    temp = *p1;
    *p1 = *p2;
    *p2 = temp;
    printf("Inside swapRef(): *p1 = %d, *p2 = %d\n", *p1, *p2);
}

int main() {
    int a = 10, b = 20;

    printf("Before swap: a = %d, b = %d\n", a, b);
    swapRef(&a, &b); // Memory addresses of 'a' and 'b' passed
    printf("After swap:  a = %d, b = %d\n", a, b);

    return 0;
}

Output:

Before swap: a = 10, b = 20
Inside swapRef(): *p1 = 20, *p2 = 10
After swap:  a = 20, b = 10

6.4 Passing Arrays To Functions: Idea Of Call By Reference

When an array is passed to a function in C, the name of the array decays into a pointer pointing directly to its first element (base address).

Base Address Principle: Array parameters are ALWAYS passed using Call by Reference automatically because the array name represents &array[0].

Array Parameter Syntax:

// Method 1: Formal parameter as unsized array
void printArray(int arr[], int size);

// Method 2: Formal parameter as pointer
void printArray(int *arr, int size);

Code Example: Modifying Array Elements Inside a Function

#include <stdio.h>

// Function to multiply each array element by 2
void doubleElements(int arr[], int size) {
    int i;
    for (i = 0; i < size; i++) {
        arr[i] = arr[i] * 2; // Directly modifies caller's array memory
    }
}

int main() {
    int numbers[5] = {1, 2, 3, 4, 5};
    int i;

    printf("Original Array: ");
    for (i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }

    // Passing array to function (passes base address)
    doubleElements(numbers, 5);

    printf("\nModified Array: ");
    for (i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n");

    return 0;
}

Output:

Original Array: 1 2 3 4 5 
Modified Array: 2 4 6 8 10

Line-by-Line Execution Explanation Table

Line / Statement Execution Breakdown
int numbers[5] = {1, 2, 3, 4, 5}; Allocates contiguous memory for 5 integers and initializes them. numbers points to &numbers[0].
doubleElements(numbers, 5); Passes base address of numbers to formal parameter arr[] and size integer 5 to size.
arr[i] = arr[i] * 2; Calculates offset address using base address (*(arr + i)) and doubles actual values in main's memory block.
printf("%d ", numbers[i]); Prints the mutated array elements 2 4 6 8 10 directly from main() scope.
